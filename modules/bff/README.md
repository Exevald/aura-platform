# BFF

Backend-for-frontend личного кабинета. Публичный API `/api/bff/v1/me` агрегирует профиль текущего пользователя через gRPC `user`; собственными продуктовыми данными сервис не владеет.

Gateway передаёт проверенный `X-Auth-User`. BFF поддерживает чтение и изменение профиля, переводит доменные gRPC-коды в HTTP 400/404/409/503 и не принимает решений о сессии или доступе к модулям.

Проверка: `mise run //modules/bff:test`.
